## 1. Background And Problem

Enterprises need a tenant-safe voice generation platform that unifies TTS, transcription, translation, music, sound effects, and multi-provider async tasks while persisting generated media into SDKWork Drive. Prior voice logic lived in appbase and lacked isolated ownership, SDK contracts, and production-grade task reconciliation.

## 2. Target Users

| Persona | Need |
| --- | --- |
| End user (IM PC embed) | Submit TTS jobs, preview/download generated audio |
| Application integrator | Consume `@sdkwork/voice-app-sdk` with SdkWork v3 envelopes |
| Platform operator | Manage provider routes, inspect tasks, replay webhooks, retry Drive sync |
| Generation worker | Drain queued tasks, apply provider results via `tasks.reconcile` |

## 3. Goals And Non-Goals

### Goals

- Normalize all provider outcomes into `voice_generation_task`, artifacts, and Drive sync rows
- Enforce tenant isolation on app/backend read paths
- Support standalone gateway + external workers for cloud and on-prem deployment
- Materialize OpenAPI authorities and generated SDK families

### Non-Goals

- Provider implementation inside this repository (owned by claw-router)
- Billing meter settlement (platform billing integration is a follow-on phase)
- Real-time voice clone training UI (market clone remains SDK-backed roadmap item)

## 4. Scope

- Rust HTTP plane: app-api, backend-api, webhook ingress, Drive sync processor
- TypeScript workers: generation worker, drive-sync worker
- PC embed packages: speech and market surfaces for IM host
- OpenAPI/SDK: `sdkwork-voice-app-sdk`, `sdkwork-voice-backend-sdk`

## 5. User Scenarios

1. **TTS submit and preview**: User enters text in IM PC speech view → `speech.create` → generation worker reconciles provider result → user polls task and plays audio asset.
2. **Async music/video**: App creates music task → provider returns async task id → webhook or worker reconcile completes task → artifacts sync to Drive AI-generated space.
3. **Operator retry**: Failed Drive sync row appears in backend list → drive-sync worker or operator calls `artifactDriveSync.retry`.
