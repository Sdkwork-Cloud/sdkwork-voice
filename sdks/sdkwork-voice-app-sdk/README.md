# SDKWork Voice App SDK

Generator-owned app/client SDK family for `sdkwork-voice-app-api`.

Run `pnpm materialize:openapi` from the `sdkwork-voice` root to refresh the OpenAPI authority and derived sdkgen inputs, then run `.\sdks\sdkwork-voice-app-sdk\bin\generate-sdk.ps1` to generate language transports through the canonical SDKWork generator.
