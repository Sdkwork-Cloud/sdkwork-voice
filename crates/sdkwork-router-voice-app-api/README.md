# sdkwork-router-voice-app-api

SDKWork Voice app-api Rust route catalog.

This crate owns the `/app/v3/api/voice` route manifest input used by
`sdks/materialize-voice-v3-openapi-boundaries.mjs` to materialize
`sdkwork-voice-app-api` into the `sdkwork-voice-app-sdk` family.

Verification:

```powershell
cargo test -p sdkwork-router-voice-app-api
```
