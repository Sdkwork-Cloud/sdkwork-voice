# sdkwork-router-voice-backend-api

SDKWork Voice backend-api Rust route catalog.

This crate owns the `/backend/v3/api/voice` route manifest input used by
`sdks/materialize-voice-v3-openapi-boundaries.mjs` to materialize
`sdkwork-voice-backend-api` into the `sdkwork-voice-backend-sdk` family.

Verification:

```powershell
cargo test -p sdkwork-router-voice-backend-api
```
