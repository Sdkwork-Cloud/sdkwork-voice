# sdkwork-voice-common

Shared voice application root for contracts, provider adapter, and generation worker packages consumed by `apps/sdkwork-voice-pc` and backend orchestration.

Packages:

- `@sdkwork/voice-contracts`
- `@sdkwork/voice-provider-adapter`
- `@sdkwork/voice-generation-worker`
- `@sdkwork/voice-drive-sync-worker`
